MODEL REALITY CHECK

예측은 얼마나 빗나갔을까?

최근 6개 비중첩 구간에서, 각 시점 이전 126개 수익률만 사용해 21거래일 뒤를 예측했습니다.

종목모델 평균 오차가격 유지 평균 오차범위 내 실제값연 변동성최근 252거래일 최대 낙폭

평균 오차는 MAPE(절대 백분율 오차)로 낮을수록 좋습니다. 가격 유지는 시작 가격을 그대로 예상하는 기준 모델입니다. 검증 대상은 배당 조정 수익률을 시작 가격에 적용한 값이며, 1개월 검증은 연말 예측의 정확도를 검증한 결과가 아닙니다. 6회 표본은 매우 작습니다.

HOW IT WORKS

분석 방법과 한계

  1. Yahoo Finance의 2년 일별 데이터 중 2026-09-11까지 사용합니다. 종가는 차트에, 배당·분할 조정 종가는 수익률 분석에 사용합니다.
  2. 최근 126거래일 로그 수익률의 연환산 평균을 25%만 반영하고 ±35%로 제한합니다. 이는 추세 과대연장을 줄이려는 설계 가정으로, 최적화된 계수가 아닙니다.
  3. 기준값 = 종가 × exp(완화 추세 × 남은 연수). 상·하단 = 기준값 × exp(±1.2816 × 연 변동성 × √남은 연수). 연 변동성은 표본 표준편차 × √252입니다.
  4. 상수 추세·변동성·정규 로그수익률을 가정합니다. 실적, 금리, 환율, 관세, 급격한 시장 변화나 미래 배당을 직접 예측하지 않습니다. 증권사 목표주가나 기업가치 평가 모델이 아닙니다.

투자 판단을 보조하는 통계 시나리오입니다. 수익이나 원금을 보장하지 않으며 매수·매도 권고가 아닙니다. 자동 갱신되지 않는 분석 스냅샷입니다.
